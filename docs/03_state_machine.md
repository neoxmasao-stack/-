# 03_state_machine

## 状態遷移
INIT → VALIDATING → (AML_REVIEW | APPROVAL_REQUIRED | APPROVED)
APPROVED → RTGS_PENDING → EXTERNAL_ACK → FINALIZED
任意状態 → FAILED → (RETRYING | MANUAL_REVIEW)
FINALIZED 後に不整合検知時は RECONCILIATION_REQUIRED

## 各状態の定義
- INIT: 受付直後
- VALIDATING: 入力・制約チェック
- AML_REVIEW: AML/KYC/PEP/Sanctions確認
- APPROVAL_REQUIRED: 人的承認待ち
- APPROVED: 実行可能
- RTGS_PENDING: 決済基盤処理待ち
- EXTERNAL_ACK: 外部応答待ち
- FINALIZED: 確定
- FAILED: 失敗
- RETRYING: 自動再試行中
- MANUAL_REVIEW: 手動審査中
- RECONCILIATION_REQUIRED: 照合作業要
